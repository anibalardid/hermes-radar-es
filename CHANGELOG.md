## [0.1.0] - 2026-04-21

### Added
- Sección **Herramientas** separada de Skills, con herramientas nativas y plataformas externas (Paperclip, OpenShell, Self-Evolution)
- **Trucos categorizados**: 22 tips en 6 categorías (Configuración, Automatización, Memoria y Skills, Plataformas, DevOps, Tips ocultos)
- Grid de 2 columnas con max-height y scroll para trucos
- Code blocks estilizados con monospace y tema dark/light
- Cache-busting dinámico con `version.js` + `?v=` param en CSS y JS
- Badge de versión dinámica en el header (sincronizado con `version.js`)
- Nav link "herramientas" en desktop y mobile

- "Skills y herramientas" → "Skills" + "Herramientas" como secciones separadas
- Card de Skills en home ahora linka solo a Skills; nueva card de Herramientas
